# Quantifying the S8 tension with redshift-space distortions

Notebook for **Benisty 2021, Phys. Dark Univ. 31, 100766** ([arXiv:2005.03751](https://arxiv.org/abs/2005.03751)).

MCMC fits and Gaussian-process regression of the fσ8(z) compilation, used to reconstruct the growth history without a model and to measure S8.

| File | Content |
|---|---|
| `Growth2.txt` | fσ8 data: z, fσ8, error |
| `fsig8GPM.ipynb` | MCMC fit and GP reconstruction |

If you use this, please cite Benisty 2021, Phys. Dark Univ. 31, 100766.
